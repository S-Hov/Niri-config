# Настройка охлаждения и управления вентиляторами (Lenovo Legion)

Конфигурация аппаратного управления охлаждением для совместимых ноутбуков
**Lenovo Legion**. Репозиторий первоначально создавался для **Legion R9000P
ADR10 / 83LV**, но проверка показала, что его EC этой версией драйвера не
поддерживается.

> [!CAUTION]
> **Legion R9000P ADR10 / 83LV с BIOS RLCN сейчас не поддерживается.**
> Не запускайте установщик старой версии и не используйте `force=1` для записи
> кривой. Драйвер подставляет несовместимую таблицу `GKCN`, выдаёт ложные
> температуры/RPM и частично записывает кривую. Обновлённый `install.sh`
> распознаёт эту модель и завершает работу без изменений.

Для безопасного возврата `83LV/RLCN` к штатному управлению выполните:

```bash
sudo ./cooling/disable-unsupported-83lv.sh
sudo reboot
```

## Зачем это нужно

1. **Особенности контроллера Lenovo (EC):** На ноутбуках Legion вентиляторы управляются напрямую микроконтроллером (Embedded Controller), а стандартное ядро Linux «из коробки» не видит датчики оборотов (RPM) и не имеет доступа к кривым кулеров.
2. **Пассивный режим по умолчанию:** Без фирменного софта (Lenovo Vantage / Legion Toolkit из Windows) прошивка держит вентиляторы на минимальных оборотах вплоть до 85–90°C, из-за чего процессор сильно греется даже при умеренной нагрузке.
3. **Решение:** Модуль ядра `legion_laptop` в связке с демоном `legiond` и настроенными пользовательскими кривыми дает стабильный ранний обдув и защищает процессор от перегрева.

## Структура каталога

| Файл / Каталог | Описание | Куда устанавливается |
| --- | --- | --- |
| `presets/balanced-ac.yaml` | Сбалансированная кривая кулеров при питании от сети | `/etc/legion_linux/` |
| `presets/balanced-battery.yaml` | Сбалансированная кривая кулеров при работе от батареи | `/etc/legion_linux/` |
| `presets/performance-ac.yaml` | Агрессивная кривая охлаждения для производительного режима | `/etc/legion_linux/` |
| `presets/performance-battery.yaml` | Производительная кривая при работе от батареи | `/etc/legion_linux/` |
| `presets/legiond.ini` | Конфигурация системного демона управления питанием и кулерами | `/etc/legion_linux/` |
| `modprobe/legion.conf` | Параметр `force=1` для загрузки драйвера на новых ревизиях Legion | `/etc/modprobe.d/` |
| `install.sh` | Скрипт автоматической установки, применения патча и перезапуска служб | — |

## Быстрая установка

Запустите скрипт установки с правами суперпользователя:

```bash
sudo ./cooling/install.sh
```

Скрипт автоматически:
1. Скопирует `modprobe/legion.conf` в `/etc/modprobe.d/legion.conf`.
2. Скопирует профили и конфиг демона в `/etc/legion_linux/`.
3. Проверит наличие `legion_cli` (системный Python-файл больше не патчится).
4. Перезагрузит модуль ядра `legion_laptop` с флагом `force=1`.
5. Включит и перезапустит системную службу `legiond`.
6. Запишет текущий профиль охлаждения в контроллер.

## Профили охлаждения

### 1. Производительный профиль (`performance-ac.yaml` — Агрессивный)
Рассчитан на тяжелые нагрузки, игры и компиляцию кода:
* **до 38°C:** ~2500 RPM (базовый легкий обдув)
* **45°C:** ~3200 RPM (быстрый подхват оборотов до начала перегрева)
* **52°C:** ~4000 RPM (активное охлаждение уже на умеренных температурах)
* **60°C:** ~4700 RPM (уверенное охлаждение)
* **68°C:** ~5200 RPM (высокие обороты до достижения критических температур)
* **74°C:** ~5500 RPM (интенсивная продувка)
* **80°C+:** 5800–6000 RPM (максимальная мощность вентиляторов)

### 2. Сбалансированный профиль (`balanced-ac.yaml`)
Оптимален для повседневной работы, веб-серфинга и просмотра видео:
* **до 45°C:** ~1800 RPM (бесшумно)
* **50–65°C:** 2300–3400 RPM (плавный подъем)
* **65–75°C:** 4000–4600 RPM (уверенный обдув)
* **80–85°C:** 5000–5400 RPM (активный сброс тепла)
* **90°C+:** 5600–5800 RPM (максимум)

## Как этим пользоваться

### 1. Переключение режимов работы
* **Аппаратные клавиши:** Нажатие комбинации **`Fn + Q`** циклически переключает режимы. Цвет светодиода кнопки питания меняется:
  * **Красный:** Режим Performance (активирует агрессивную кривую)
  * **Белый:** Режим Balanced (сбалансированная кривая)
  * **Синий:** Режим Quiet (тихий режим)
* **Через консоль:**
  ```bash
  powerprofilesctl set performance
  powerprofilesctl set balanced
  powerprofilesctl set power-saver
  ```

### 2. Управление через CLI (`legion_cli`)
* **Включить принудительный максимальный обдув (Extreme Cooling / 100%):**
  ```bash
  sudo legion_cli maximumfanspeed-enable
  ```
* **Отключить принудительный максимум:**
  ```bash
  sudo legion_cli maximumfanspeed-disable
  ```
* **Принудительно записать файл кривой в контроллер:**
  ```bash
  sudo legion_cli fancurve-write-file-to-hw /etc/legion_linux/performance-ac.yaml
  ```
* **Применить кривую текущего профиля к железу:**
  ```bash
  sudo legion_cli fancurve-write-current-preset-to-hw
  ```

### 3. Графический интерфейс (`legion_gui`)
Графическое приложение нужно запускать **от обычного пользователя** (без `sudo`), так как в Wayland-сессии `sudo` блокирует доступ к дисплею:
```bash
legion_gui
# или явно указав бэкенд Wayland:
QT_QPA_PLATFORM=wayland legion_gui
```
При нажатии на кнопки записи кривых или настроек приложение само запросит пароль администратора через графическое окно Polkit (`pkexec`).

### 4. Мониторинг температур и вентиляторов
Благодаря модулю `legion_laptop` датчики кулеров доступны через `lm-sensors`:
```bash
sensors
```
В секции `legion_hwmon-isa-0000` отображаются реальные обороты `Fan 1` и `Fan 2` (RPM).

## Важные замечания и устранение неполадок

* **Флаг `force=1`:** Новые ревизии Legion (например, `83LV` / 2024+) могут отсутствовать в базовом списке моделей модуля. Параметр `options legion_laptop force=1` в `/etc/modprobe.d/legion.conf` обязателен.
* **Ошибка `[Errno 95] Operation not supported`:** Не подавляйте её глобальным
  `try/except OSError`: это скрывает частичную запись и несовместимую карту EC.
  На `83LV/RLCN` после такой ошибки следует прекратить запись пользовательских
  кривых и вернуть управление штатной прошивке.
* **Не используйте `maximumfanspeed` на `83LV/RLCN`:** на близкой аппаратной
  ревизии RLCN включение полного обдува не снимается командой отключения и
  требует перезагрузки.
* **Служба `legiond`:** Демон отслеживает переключение питания (AC/Battery) и смену профилей (`Fn + Q`), автоматически перезагружая соответствующую кривую из `/etc/legion_linux/`. Статус проверяется командой:
  ```bash
  systemctl status legiond.service
  ```
